# Claims ledger

Every fact about the outside world that our pages and drafts repeat, with the one source it comes
from and when it was last checked. A draft that contradicts this ledger is rejected; a fact that is
not here must be verified at its primary source and added before it is published.

The business's own facts (prices, plans, contact details, delivery time, credentials) are **not**
here: they live in the files named in `site.md` and are read from there.

The monthly autopilot run re-opens each source and updates "Checked". If a value changed, every
guide that states it is fixed in the same run.

## Not confirmed — do not state as fact

- "A ticket is valid for 3 hours": seen on third-party pages; not confirmed on an official page.
  Write it only as "commonly enforced" with that caveat, or leave it out, until the owner or an
  official source confirms.
