# Your photographs go here

These filenames are already wired up in `lib/images.ts`. Drop a file in with the
exact name below and it replaces the stock placeholder everywhere it appears —
no code change needed.

| File | Where it shows | Best frame to use |
|------|----------------|-------------------|
| `hero.jpg` | Homepage hero, full bleed | Wide, landscape. Leave the LEFT third uncluttered — the headline sits there. |
| `sunrise.jpg` | Sunrise package card + page | A guest at the Taj at sunrise |
| `pre-wedding.jpg` | Couple & Pre-Wedding | A couple, editorial |
| `guided-photo-tour-small.jpg` | Guide + Photo, small group | 2–5 guests at Agra Fort or the Taj |
| `guided-photo-tour-large.jpg` | Guide + Photo, large group | A family or group together |
| `transport-guide.jpg` | Transport + Guide | Agra monument or the car — Agra only, never Delhi |
| `taj-agra-fort.jpg` | Heritage Trail | Agra Fort |
| `full-day.jpg` | Full Day Agra | Mehtab Bagh / back-side sunset |
| `sunrise-luxury-innova.jpg` | Luxury tour, Innova | Couple or small family |
| `sunrise-luxury-urbania.jpg` | Luxury tour, Urbania | Larger group |

Guidance: landscape (3:2 or 16:9), at least 1600px wide, under ~400KB each
(export at quality 80). JPG or WebP. They are your own work, so no credit line
is needed.

Downloading them from Google Business: open your profile, Photos, tap a photo,
then the three-dot menu → Download. Google's copies are compressed; if you have
the originals, use those instead.
